Identity of an element

Atomic Number

The atomic number identifies the element and equals the number of protons in its nucleus. For a neutral atom, the number of electrons equals the number of protons too.

Atomic Number = Number of Protons  ·  (neutral atom) Number of Electrons = Number of Protons

Challenge: Guess the Element

Count the protons shown in the nucleus, find that atomic number on the periodic table, then name the element.

Protons + neutrons

Mass Number

Mass number is the total count of protons and neutrons in the nucleus — not the periodic table's average atomic mass.

Mass Number = Protons + Neutrons
Number of Neutrons = Mass Number − Atomic Number

Worked Example — Sodium-23

Atomic number = 11 · Mass number = 23 · Protons = 11 · Neutrons = 23 − 11 = 12 · Electrons = 11 (neutral atom)
